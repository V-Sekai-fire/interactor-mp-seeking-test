# interactor-mp-seeking-test

A Godot test project that plays a short open film and seeks it with a slider.

## What it is for

It checks that the engine's video stream player jumps to the position a slider sets, on a WebM
clip of an openly licensed short film.

## Run

Open the project in the editor and run its main scene.
